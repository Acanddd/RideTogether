## Current release / 当前版本：Full 1.2

Drive as your current character, use first-person driving, and configure rear passengers and appearances.
使用当前角色驾驶、第一人称驾驶，并配置后排角色及外观。

## Install / 安装

Close the game and launcher. Extract the player ZIP. In Aurora, add and enable `RideTogetherFullRuntime.asi` under Third-party Modules, then import and enable `RideTogether-Full-1.2-Resources.zip` in Mod Manager.

退出游戏及启动器，解压玩家包。在 Aurora「第三方模块」添加并启用 `RideTogetherFullRuntime.asi`，再在「Mod 管理器」导入并启用资源 ZIP。

Open the panel from the phone menu or press the main-keyboard `=/+` key; `Esc` closes it. / 手机菜单或主键盘 `=/+` 打开面板，`Esc` 关闭。
